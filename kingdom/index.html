    麦门制霸图 · 玩法

    这是一张把真实门店重绘成游戏地图的征服板。全城每一家麦当劳都是一座城邦：旗舰店是王都，商场店是城镇，得来速与社区店是边哨。每家城邦按 Voronoi 领地划分疆域——你吃下一家店，就点亮它的整片领地。

    版图占比按领地面积计算，不是门店数：吃在门店密集的城区，推进慢；远征密云延庆，一步开疆一大片。

    战功= 城邦等级（王都 500 / 城镇 200 / 边哨 100）× 远郊 1.5 倍，首次攻入一个郡另有开疆奖 150。

    称号随版图晋升：麦门路人 → 见习麦民 → 麦田巡逻官 → 金拱门骑士 → 堡垒男爵 → 边疆侯爵 → 巨无霸公爵 → 麦门亲王 → 制霸者·麦门之主。

    操作：滚轮缩放、拖拽平移、双击复位；悬停查看城邦情报；演示模式下点击未征服城邦即可攻占，或点右上「发起征伐」。

    接真实数据：在仓库目录运行 python3 kingdom/tools/fetch_mcd_data.py（需 MCD_MCP_TOKEN），生成 data/stores.json 与 data/visits.json 后刷新页面即变为你自己的王国。历史订单接口只返回最近约 10 单，visits.json 是累积档案，请妥善留存。

    隐私提醒：真实门店名≈位置信息。公开分享或部署前请用 fetch 脚本的 --sanitize 生成脱敏版。
